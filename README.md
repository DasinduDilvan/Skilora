# Skillora 🚀

> A simple freelance marketplace connecting **Clients** with **Freelancers** for Design, Video, and IT projects.

## ✨ Features

- 👤 Client & Freelancer accounts
- 📌 Post and browse projects
- 📝 Apply for projects
- 💼 Manage projects
- 💳 PayHere Sandbox payments
- ⭐ Reviews & ratings
- 🛠️ Admin management

## 🧩 Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express.js
- **Database:** MongoDB Atlas
- **Storage:** AWS S3
- **Payment:** PayHere Sandbox
- **Deployment:** Vercel + AWS EC2

## 📁 Structure

```text
Skillora/
├── client/     # React frontend
├── server/     # Express backend
└── README.md
```

## 🎯 Main Flow

```text
Client → Post Project
       ↓
 Freelancer → Apply
       ↓
 Client → Hire
       ↓
 Project → Payment → Review
```
